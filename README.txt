MapleMeter Warm · 暖光版

Windows x64 经验统计工具。完整解压后运行 MapleMeter-Warm.exe。
需要 .NET Framework 4.x / WPF。保留 runtime、templates、fonts 等全部文件，无需安装 Python 或 Tesseract。

打开游戏，展开小地图并保持状态栏可见。识别后自动开始记录。
设置可选择窗口、手动框选识别区域、调整字体/缩放/皮肤。
主界面显示预计每小时净经验、升级预估、累计净经验、平均效率和分钟趋势；支持悬浮窗、历史和每日统计。

Ctrl+Alt+空格：暂停 / 继续
Ctrl+Alt+L：返回主窗口

15 秒无游戏前台键鼠操作自动暂停，可靠经验变化后恢复。连续暂停 15 分钟后结束并保存。
历史仅保留有效时长严格超过 10 分钟的记录，短记录可计入每日统计。请正常结束或退出以保存。

记录和设置：%LOCALAPPDATA%\MapleMeter-Warm
自动使用当前 Windows 用户目录，不绑定解压路径。同一用户的程序副本共用记录。
设置 → 打开记录目录，可备份或迁移整个目录。
正常运行不保存或上传游戏截图。异常日志可能包含本机路径，分享前请检查。

最近 5 分钟指有效记录时间。自动暂停恢复计入经验变化但不补计暂停时间，效率可能偏高。
目前主要适配英文经典客户端；最小化、遮挡、布局变化可能影响识别。
